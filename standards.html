Platform standards

The standing rules we work to on the LSH Training Portal and the LSH Knowledge Base. Already implemented — this board is the collation.

STANDARDS.md
README · SIMULATORS · CODEMAP

01 Sign-in & access

  • One sign-in, on the Portal; a name alone never signs anyone in.
  • SSO is an HMAC ticket — 5 minutes, used once; never a shared password.
  • A ticket never signs in an admin (Ring Channel aside): admin prompt ?admin=1.
  • Batch ID B + MMDDYY; a program keys a trainee on first, last and batch.
  • Gating is server-side; no heartbeat for 90 s ends the session.
  • The site Lock is the Master Account's alone.

02 Simulators

  • Shell order: app.js · portal.js · sim.js, then the simulator's own.
  • Identity before first paint — Sim.ready / Sim.restore().
  • A signed-in trainee always practices as their own account.
  • Scores are computed from the scorecard; the AI writes feedback, never the number.
  • Extend with a pack, don't add a simulator. Claim it in SIMULATORS.md first.
  • Trainee-facing text avoids the word "AI".

03 Navigation

  • Every page loads /portal-nav.js and shows "← Back".
  • Portal pages open in the same tab; only the courses open a new one.
  • Home links go to /index.html?stay=1.
  • One admin bar, one trainee bar — from PortalNav.

04 Page style

  • theme.css loads last; the portal look is the default.
  • Backdrop tuned only by --portal-photo / --portal-wash / --portal-base.
  • Glass panels: background shorthand, never background-image.
  • AA contrast against the photo, not a white card. Orange is a fill.
  • IBM Plex Sans + Mono; navy #0f2148, orange #f97316.
  • One Blueprint engine, copied to every platform.

05 Request budget

  • Every LSH site shares one monthly allowance — ask sparingly.
  • One /api/live every 20 s; 60 s in a background tab.
  • Heartbeat 30 s; progress once a minute, only when in view.
  • Stay under KV's 1,000 operations per request.

06 Data & secrets

  • Shared databases: a schema change stays backward compatible.
  • Course keys keep their prefixes — ft: cm: pd: md:.
  • Secrets live in Cloudflare only; a missing one says so plainly.
  • CSV exports quote against formula injection; files typed by content.
  • Helpers live once: functions/_utils.js · src/util.js.

07 Knowledge Base

  • Nothing is overwritten: every save is a version.
  • Every edit waits for approval; nobody approves their own.
  • Tenured VAs, reviewers and admins edit; Info Access reads.
  • Safe Markdown; titles in sentence case.
  • Scope is the law practice. Sources de-identified, credentials never copied.
  • Imports are idempotent, keyed by legacy_ref.

08 CI & uptime

  • Checks run on every PR and every push; red means broken.
  • Everything parses, every local file exists, JSON is valid, Functions build.
  • Smoke test opens every page at desktop and phone width — no sideways scroll.
  • A new page goes in PAGES in smoke.cjs.
  • CI never deploys. Uptime sweeps at :07 and :37 and opens a site-down issue.

09 Working practice

  • Work the designated branch; no PR unless one is asked for.
  • Validate before pushing — a red CI costs more than the finding.
  • Keep each fix minimal; docs change in the same commit.
  • Weekly inventory: every finding needs a file:line and a failure path.
