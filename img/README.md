# The LSH logo

There is one LSH logo: **`/lsh-logo-dark.png`** (in the repository root), the logo made for dark backgrounds,
with a white outline and a white "LEGAL SUPPORT HELP" wordmark. Every page uses it: the hero cards
(portal-nav.js puts it there), the top bars, the sign-in cards (on a navy chip), the landing page and the
dashboard's sidebar. Show it on navy or another dark surface, never on white or a light panel.

The older versions (`logo.svg`, `logo.png` and the script that traced one from the other) were removed so
nobody reaches for the wrong one. The CMS (LSH CaseWorX) and LSH CommX keep their own logos.
